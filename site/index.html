The loop

Save it. Keep it. Find it. Carry it.

  1. 01

    Save from the place you already are

    Paste a link or drop a file into the capture bar. The same store also accepts Safari, Share, Services, Dock drop, Shortcuts, Chrome, and the menu bar icon.

    Artifact Capture bar copy in the shipping app: “Paste a link or drop a file.”

  2. 02

    Keep it on disk, not in an account

    The library is a local SQLite file. A public web link may still be fetched for a title and preview unless you turn previews off. Private and loopback addresses are stored as bookmarks and are not fetched.

    Artifact Retention is honest: bookmark, copied file, or excerpt — stated on the card, not implied.

  3. 03

    Find it without building a filing system first

    Command-F searches titles, notes, tags, and excerpts. Layouts are Cards, Rows & Columns, and Covers. Shelves are places, not a mandatory taxonomy.

    Artifact Search field copy: “Search title, notes, tags, excerpts.”

  4. 04

    Leave with a copy you can restore

    Export and restore use a .stowmark archive from Settings. The alpha is an evaluation build: keep your own export if the library matters.

    Artifact GitHub release assets include the DMG and a SHA-256 sidecar.

First launch

Right-click, then Open.

  1. Drag Stowmark into Applications

    Mount the DMG and copy the app. Do not run it from the disk image.

  2. Open it through Gatekeeper

    This build is signed with Developer ID Application: CHARLES B BONETTI (6KZQK3A2B3). It is not notarized. First launch: right-click the app → Open.

  3. Save one thing

    Paste a link into the capture bar. Empty library copy in the app: organization can wait. Nothing there is sample data.

Designed constraints

What this alpha will not pretend to be.

Name
Developed as My Mind. Renamed to Stowmark to stay clear of mymind.com. Same local library.
Notarization
Right-click → Open is required until a notarized build ships.
Chrome
Native messaging host and unpackable extension are included. The Chrome Web Store listing is not published.
Media types
GIF, WebP, TIFF, SVG, and video are not accepted yet.
