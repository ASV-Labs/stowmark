The loop

Save it. Keep it. Find it. Carry it.

  1. 01

    Save from the place you already are

    Paste a link or drop a file into the capture bar. The same store also accepts Share, Services, Dock drop, Shortcuts, the menu bar icon, and an opt-in clipboard watcher. Browser extensions are Coming soon.

    Artifact Capture bar copy in the shipping app: “Paste a link or drop a file.”

  2. 02

    Keep it on disk, not in an account

    The library is a local SQLite file. A public web link may still be fetched for a title and preview unless you turn previews off. Private and loopback addresses are stored as bookmarks and are not fetched. This build also copies GIF and WebP images, and keeps an on-disk article when the page is extractable.

    Artifact Retention is honest: bookmark, copied file, or excerpt — stated on the card, not implied.

  3. 03

    Find it without building a filing system first

    Command-F searches titles, notes, tags, and excerpts. Layouts are Cards, Rows & Columns, and Covers. Shelves are places, not a mandatory taxonomy.

    Artifact Search field copy: “Search title, notes, tags, excerpts.”

  4. 04

    Leave with a copy you can restore

    Export and restore use a .stowmark archive from Settings. Archives from earlier builds still restore. The alpha is an evaluation build: keep your own export if the library matters.

First launch

Right-click, then Open.

  1. Drag Stowmark into Applications

    Mount the DMG and copy the app. Do not run it from the disk image.

  2. Open it through Gatekeeper

    This build is signed with Developer ID Application: CHARLES B BONETTI (6KZQK3A2B3). It is not notarized. First launch: right-click the app → Open.

  3. Save one thing

    Paste a link into the capture bar. Empty library copy in the app: organization can wait. Nothing there is sample data.

Designed constraints

What this alpha will not pretend to be.

Library
Local on this Mac. This build migrates an existing library, including older Application Support folders and App Groups.
Notarization
Right-click → Open is required until a notarized build ships.
Chrome / Safari extensions
Coming soon in this alpha. Use Share, Services, paste, drop, or the menu bar. A Chrome Web Store listing is not published yet.
Media types
GIF and WebP copy in this alpha. TIFF, SVG, and video are not accepted yet.
